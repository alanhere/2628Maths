1. Connect to the site

How do I get a token?
  1. Sign in to github.com, click your picture, then Settings.
  2. Scroll down to Developer settings, then Personal access tokens, then Fine-grained tokens, then Generate new token.
  3. Name it “Lesson publisher”. Set the expiry to a year.
  4. Under Repository access choose Only select repositories and tick your class websites.
  5. Under Permissions, then Repository permissions, set Contents to Read and write.
  6. Click Generate token and copy it (it starts github_pat_). You only see it once, so keep it in a password manager.
